# Scheduled integration tests for group sequential design R packages

This repository runs scheduled integration tests of the following R packages for
group sequential design of clinical trials:

* [gsDesign](https://github.com/keaven/gsDesign)
* [gsDesign2](https://github.com/Merck/gsDesign2)
* [simtrial](https://github.com/Merck/simtrial)
